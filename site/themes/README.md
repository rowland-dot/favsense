# 主题记录

## 当前：Xiaohongshu Stationery Editorial v5

活动主题直接位于 `site/styles.css`，不通过运行时主题包加载。

核心色彩：

- 品牌红：`#FF2442`，只用于品牌标记和极少量来源提示
- 正文黑：`#222222`
- 纯白：`#FFFFFF`
- 页面灰：`#F7F7F7`
- 边界灰：`#EDEDED`
- 信息蓝：`#5B7CFA`（样式表里 `--cobalt` 的实际取值；此前这里写的 `#3569E8` 是早期取值，从未进入样式表，现以样式表为准）
- 工作流深紫：`#6F3CC3`
- 自动化洋红：`#D9368B`
- 开发橙：`#E66B00`
- 数据金黄：`#B58B00`
- 增长黄绿：`#6B9E1B`
- 知识翠绿：`#008F66`
- 本地模型青：`#00889A`
- AI 设计砖红：`#B54335`

主体与知识卡保持白底、黑字和浅灰边界，但不等于无色。品牌红只用于标志与关键选择；文具色按照知识主题稳定映射，用于主题圆点、卡片顶边、黑色标题下划线、详情应用便签和项目小标记。颜色不表达价值、优先级、处理状态或证据状态，也不会改变卡片的大面积白色画布。默认使用亮色，仍可手动切换深色版本。

## 文字尺寸与文字色 token

- 字号下限：`--text-xs` = 11px，页面上任何文字都不得更小；标签、徽章、计数、说明行原先的 7–10px 全部改为引用它。
- 品牌红 `#FF2442` 与信息蓝 `#5B7CFA` 只做填充色和标记色（品牌标、圆点、卡片顶边、选中描边）。凡是拿它们当文字色，或在它们上面放白字，改用文字用途 token：
  - `--text-red`：浅色 `#C8102E`，深色 `#FF667D`
  - `--text-blue`：浅色 `#3A58D0`，深色 `#8AA0FF`
  - `--fill-blue`（白字的底色）：两种主题均为 `#3A58D0`
- 对比度下限 WCAG AA（正文 4.5:1，大字 3:1），由 `site/e2e/design-text-legibility-regression.spec.mjs` 在工作台与公开两个视图、桌面与移动、亮色与暗色下检查。
